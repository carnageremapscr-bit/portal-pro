ECU Database FAQ

How many vehicles does the tuning database cover?

Over 15,000 UK-registered vehicles across 30+ manufacturers. We cover petrol and diesel cars, vans, and commercial vehicles with BHP and torque data for stages 1, 2, and 3.

Can I access the tuning database via API?

Yes. We provide a REST API that returns JSON data. Query by registration number, make/model, or engine code. The API includes vehicle identification via DVLA data.

How accurate is the remapping data?

All data is sourced from real dyno results and verified tuning files. Results are accurate to within 5-10% depending on vehicle condition, fuel quality, and modifications.

Is there a free trial?

We offer a free demo so you can see exactly how the lookup works on your website before subscribing. Contact us via WhatsApp to arrange it.

What format is the data returned in?

JSON by default. The API returns vehicle details (make, model, engine, year), stock figures, and tuned figures for each stage including BHP, torque, and percentage gains.
