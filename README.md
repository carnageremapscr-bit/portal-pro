# Portal Pro

A simple, professional landing site for your automotive services: vehicle lookup widget, ECU file portal, and web design.

## Quick Start

Option 1: open the file directly

- Double‑click `index.html` to open in your browser.

Option 2: run a local server (PowerShell)

```powershell
# From the portal-pro folder
Start-Process index.html
```

Option 3: Python (if installed)

```bash
# From the portal-pro folder
python -m http.server 8080
# Then open http://localhost:8080
```

## Customize

- Update branding (logo/text) in `index.html`.
- Change WhatsApp number and contact details in the Contact section.
- Tweak colors and layout in `css/style.css`.
- Edit interactions in `js/main.js`.
