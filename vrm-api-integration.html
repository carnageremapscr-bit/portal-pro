VRM API FAQ

How does the VRM API work?

Send a request with a UK registration number and receive a JSON response with full vehicle details including make, model, MOT status, emissions, BHP, and more.

Can I integrate the API into my booking system?

Yes. The API returns JSON data that integrates into any booking system, CRM, garage management software, or custom application.

What programming languages does it support?

The API is language-agnostic. It works with JavaScript, Python, PHP, C#, Java, Ruby, Go — any language that can make HTTP requests.

Is there a rate limit?

Contact us to discuss rate limits and pricing based on your expected volume. We offer flexible plans for small businesses through to enterprise usage.

Is the data accurate and up to date?

Yes. Vehicle data is sourced from official UK databases and updated regularly to ensure accuracy of MOT, tax, and registration information.
