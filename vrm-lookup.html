FAQ

Common questions

Short, direct answers so you can choose the right delivery model.

What data sources do you use?

We aggregate DVLA, DVSA, and insurance group references. We do not expose personal keeper data-only the counts and dates needed for trade checks.

Can I embed this on my website?

Yes. The widget is responsive, WCAG-friendly, and can be branded. If you prefer API, you can hit a single REST endpoint and render results yourself.

How do you handle rate limits?

Each key has a throttle window plus IP allowlisting. We also provide burst allowances for peak periods and send alerts if you approach quota.

Do you store vehicle or user data?

We log anonymous request metadata for reliability and abuse detection. You can request log pruning or region-specific storage if required.

Can I test before paying?

We provide a free sandbox with masked data so you can validate the integration. Book a call if you need guided setup.
